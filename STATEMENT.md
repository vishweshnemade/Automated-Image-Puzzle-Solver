Project Tittle:
Automated Image Puzzle Reconstruction and Solving System

1. Problem Statement
Solving image puzzles manually can take time and requires the user to correctly identify the position of each puzzle piece. Beginners may also find it difficult to understand how an image can be divided, scrambled, and reconstructed.
The Automated Image Puzzle System is developed to provide an interactive way to create and solve image puzzles. The system allows the user to upload an image, divide it into smaller pieces, randomly scramble the pieces, and arrange them back into their original positions.
The project also provides an automated hint system that identifies where each scrambled piece belongs. This demonstrates the use of Python, image processing, randomization, and Streamlit for developing an interactive application.

2. Project
The scope of this project includes:
- Uploading an image through a web interface.
- Displaying a preview of the uploaded image.
- Resizing the image for puzzle processing.
- Dividing an image into multiple puzzle pieces.
- Supporting different grid dimensions such as 2 × 2 and 3 × 3.
- Randomly scrambling the generated puzzle pieces.
- Displaying the scrambled pieces to the user.
- Allowing the user to manually select the order of puzzle pieces.
- Checking whether the manually selected arrangement is correct.
- Providing an automated hint/solution for the scrambled puzzle.
- Displaying step-by-step instructions for reconstructing the image.
- Providing an interactive interface using Streamlit.

The current project focuses on image puzzle reconstruction and does not include advanced AI-based image recognition or computer vision algorithms.

High-Level Features
Image uploder
The user can upload an image using the Streamlit file uploader.

Image Preview
The uploaded image can be displayed before generating the puzzle.

Grid Selection

The user can select the puzzle grid dimension.

Puzzle Generation
The uploaded image is divided into smaller pieces according to the selected grid size.

Random Scrambling
The generated puzzle pieces are randomly rearranged to create the puzzle.

Manual Solving
The user can select which puzzle piece should be placed at each position.

Solution Checking
The system compares the user's arrangement with the original arrangement and displays whether the solution is correct.

Automated Hint
The system can automatically determine the correct position of each puzzle piece.

Step-by-Step Solution
The system displays instructions such as:
Example:
Step 1: Place Piece 5 at Position 1
Step 2: Place Piece 2 at Position 2
Step 3: Place Piece 8 at Position 3

Interactive Web Interface
The complete application is implemented using Streamlit, allowing the user to interact with the project through a web browser.


Project Goal
The main goal of the project is to demonstrate how Python and image-processing libraries can be combined with Streamlit to create an interactive system that can generate, scramble, check, and provide solutions for image-based puzzles
