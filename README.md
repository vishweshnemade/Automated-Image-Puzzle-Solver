# Automated Image Puzzle Solver
The Automated Image Puzzle Solver is a Python-based interactive web application developed using Streamlit and Pillow (PIL). The project allows users to upload an image and convert it into a puzzle by dividing it into smaller pieces according to a selected grid dimension, such as 2×2 or 3×3.  The system randomly scrambles the puzzle pieces and provides two ways to solve the puzzle. In the manual solving mode, the user can select the appropriate puzzle piece for each position and check whether the arrangement is correct. In the automated solving mode, the system compares the scrambled pieces with the original pieces using their image data and identifies the correct position of every piece. It then displays the solution as a sequence of steps, such as “Place Piece 4 at Position 1.”  The project demonstrates the use of Python functions, modules, image processing, lists, loops, conditional statements, randomization, Streamlit session state, and user-defined functions. It provides a simple interface for understanding how a computer can reconstruct an image puzzle automatically.
