Project Tittle:
Automated Image Puzzle Reconstruction and Solving System


home.py
This is the main Streamlit application. It should contain:
•	Image upload 
•	Image preview 
•	Grid selection 
•	Puzzle generation 
•	Puzzle scrambling 
•	Manual solution checking 
•	Automated hint/solution 
•	Solution steps


grid.py
This is separate module for creating puzzle pieces.
It contain the f() function that your home.py  calls
